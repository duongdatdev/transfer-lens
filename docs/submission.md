## Scope adaptation

a completed bank transfer, including screenshots saved after transferring money.
Merchant extraction becomes explicit sender/recipient extraction. The transfer
description is used to suggest Food, Study, Travel, Gear or Entertainment; an unclear
description requires the user to select a category. Camera capture remains available.

The original assignment rubric is provided by the course. This adaptation follows
the student's requested scenario; instructor acceptance of the changed scenario is
